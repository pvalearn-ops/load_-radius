計算模式

幾何　作業半徑 R = L·cosθ，伸臂腳銷視為位於迴轉中心。

強度　伸臂視為自腳銷起算的懸臂樑（保守，未計起伏油壓缸的支撐效果）。 軸力 N = φ(W+Wb)·g·sinθ， 起伏面彎矩 Mx = φ(W·R + Wb·R/2)·g， 側向彎矩 My = kh·W·g·L。 條件 N/A + Mx/Zx + My/Zy ≤ σy/安全係數，解出 W。

安定度　以側方腳架外緣為傾倒支點，a = B/2。車身重心在迴轉中心，伸臂重心在 R/2。 傾倒荷重 Wtip = [Wc·a − Wb(R/2 − a)] / (R − a)， 安定荷重 W = Wtip / 安定係數（預設 1.27，即傾倒荷重約 79%）。

本表僅供觀察參數影響趨勢，未計吊鉤、鋼索、伸縮段斷面變化、挫屈及底盤自身強度，不可作為實際額定荷重表使用。
